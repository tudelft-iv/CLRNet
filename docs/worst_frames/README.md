# High-error frames

Four of the highest-error Dual-Radar test frames for CRNet trained on View-of-Delft (005512 is shown in the
paper). Radar points are projected with the miscalibrated (`_a`), ground-truth (`_b`) and predicted (`_c`)
extrinsics. `dual_radar_crossdomain_per_frame_errors.csv` lists the per-frame errors for the whole test split.
